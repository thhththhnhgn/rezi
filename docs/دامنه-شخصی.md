# 🌐 وصل کردن دامنه شخصی (Cloudflare + Railway)

راهنمای کامل اتصال دامنه خودت به پنل.

---

## چرا اصلاً این کار را بکنم؟

| مزیت | توضیح |
|------|-------|
| 🚫 **دامنه Railway فیلتر است** | `*.up.railway.app` در ایران معمولاً مسدود است. دامنه شخصی این مشکل را ندارد. |
| 🔄 **قابل تعویض** | اگر دامنه سوخت، فقط رکورد DNS را عوض می‌کنی — همه لینک‌های اشتراک کاربران خودکار درست می‌شوند. |
| 🎭 **کمتر جلب توجه** | `cdn.yourdomain.com` مثل یک سایت معمولی به نظر می‌رسد. |
| ⚡ **IP تمیز کلودفلر** | می‌توانی IP بهینه انتخاب کنی. |
| 🛡 **پنهان‌سازی سرور اصلی** | با پروکسی کلودفلر، آدرس Railway تو دیده نمی‌شود. |

**پس بله، حتماً به کارت می‌آید و شدیداً توصیه می‌شود.**

---

## دو روش — کدام را انتخاب کنم؟

### 🅰️ روش A: دامنه مستقیم به Railway (پیشنهادی برای شروع)

```
کاربر → دامنه تو (کلودفلر پروکسی) → Railway → Xray
```

✅ ساده، ۱۰ دقیقه‌ای
✅ همه پروتکل‌ها کار می‌کنند
✅ IP تمیز کلودفلر

### 🅱️ روش B: دامنه روی Worker

```
کاربر → دامنه تو → Worker → Railway → Xray
```

✅ یک لایه انعطاف بیشتر
❌ پیچیده‌تر، یک hop اضافه

> **پیشنهاد من: با روش A شروع کن.** بعداً اگر خواستی، روش B را هم اضافه کن.

---

# 🅰️ روش A — قدم به قدم

## قدم ۱ — انتخاب زیردامنه

از یک **زیردامنه** استفاده کن، نه دامنه اصلی. مثلاً:

```
cdn.yourdomain.com
media.yourdomain.com
static.yourdomain.com
```

> ⚠️ **مهم:** فقط **یک سطح** زیردامنه. یعنی `cdn.yourdomain.com` ✅
> ولی `vpn.cdn.yourdomain.com` ❌ (نیاز به Advanced Certificate Manager پولی دارد)

اسم‌های بی‌ربط مثل `cdn` و `media` بهترند تا `vpn` و `proxy`.

---

## قدم ۲ — اضافه کردن دامنه در Railway

1. سرویس → **Settings** → بخش **Networking**
2. دکمه **+ Custom Domain**
3. زیردامنه‌ات را بنویس: `cdn.yourdomain.com`
4. Railway دو چیز نشانت می‌دهد — **هر دو را کپی کن**:

| نوع | مقدار نمونه |
|-----|-------------|
| **CNAME** | `abc123xyz.up.railway.app` |
| **TXT** | `_railway-verify` با یک مقدار |

> 📌 هر دو رکورد لازم‌اند. بدون TXT، Railway دامنه را تأیید نمی‌کند و ۴۰۴ می‌دهد.

---

## قدم ۳ — ساخت رکوردها در Cloudflare

داشبورد Cloudflare → دامنه‌ات → تب **DNS** → **Add record**

### رکورد اول (CNAME)

| فیلد | مقدار |
|------|-------|
| Type | `CNAME` |
| Name | `cdn` |
| Target | مقداری که Railway داد (مثلاً `abc123xyz.up.railway.app`) |
| Proxy status | 🔘 **DNS only** (ابر خاکستری) ← **فعلاً خاکستری!** |
| TTL | Auto |

### رکورد دوم (TXT)

| فیلد | مقدار |
|------|-------|
| Type | `TXT` |
| Name | همان که Railway گفت (مثلاً `_railway-verify.cdn`) |
| Content | مقداری که Railway داد |

> 🔑 **نکته حیاتی:** پروکسی را **فعلاً خاموش** (خاکستری) بگذار.
> اگر نارنجی باشد، Railway نمی‌تواند گواهی SSL بگیرد و کار نمی‌کند.

---

## قدم ۴ — صبر برای گواهی SSL

به Railway برگرد. کنار دامنه باید ببینی:

```
⏳ Issuing certificate...   →   ✅ (تیک سبز)
```

معمولاً **۱ تا ۵ دقیقه** طول می‌کشد.

تست کن:
```
https://cdn.yourdomain.com/health
```
باید `ok v3.1.0` بدهد.

> ❌ اگر گیر کرد روی "Validating": مطمئن شو رکورد TXT درست است و پروکسی خاکستری است.

---

## قدم ۵ — تنظیم SSL در Cloudflare

**قبل از روشن کردن پروکسی، این را حتماً انجام بده:**

Cloudflare → **SSL/TLS** → **Overview** → حالت را بگذار روی:

```
🔒 Full
```

| حالت | نتیجه |
|------|-------|
| Off | ❌ کار نمی‌کند |
| **Flexible** | ❌ **حلقه بی‌نهایت ریدایرکت** |
| **Full** | ✅ **درست** |
| Full (strict) | ⚠️ گاهی موقع تمدید گواهی خطا می‌دهد |

> این مهم‌ترین تنظیم است. `Flexible` باعث ارور "Too many redirects" می‌شود.

---

## قدم ۶ — روشن کردن پروکسی

حالا برگرد به **DNS** و رکورد CNAME را ویرایش کن:

```
Proxy status: 🟠 Proxied  (ابر نارنجی)
```

۱ تا ۲ دقیقه صبر کن و دوباره تست کن:

```
https://cdn.yourdomain.com/health
```

باز هم باید `ok v3.1.0` بدهد. حالا ترافیک از شبکه کلودفلر رد می‌شود.

---

## قدم ۷ — معرفی دامنه به پنل ⭐

**این قدم را فراموش نکن** — وگرنه لینک‌ها همچنان دامنه Railway را دارند.

Railway → سرویس → **Variables** → این را اضافه کن:

```env
PUBLIC_HOST=cdn.yourdomain.com
```

**Update Variables** را بزن و منتظر ری‌دیپلوی بمان.

بعد از بالا آمدن:
1. وارد پنل شو: `https://cdn.yourdomain.com/panel/`
2. **Players** → روبروی کاربر **CONFIGS**
3. کانفیگ‌ها را **دوباره کپی کن** — حالا دامنه شخصی دارند ✅

---

## قدم ۸ — تنظیمات پیشنهادی Cloudflare

Cloudflare → **SSL/TLS** → **Edge Certificates**:

| تنظیم | مقدار | چرا |
|-------|-------|-----|
| Always Use HTTPS | ✅ روشن | همه ترافیک رمزنگاری‌شده |
| Minimum TLS Version | **TLS 1.2** | سازگاری با همه کلاینت‌ها |
| Opportunistic Encryption | ✅ روشن | — |

Cloudflare → **Speed** → **Optimization**:

| تنظیم | مقدار | چرا |
|-------|-------|-----|
| Auto Minify | ❌ **خاموش** | نباید JS پنل را دستکاری کند |
| Rocket Loader | ❌ **خاموش** | پنل را خراب می‌کند |
| Brotli | ✅ روشن | — |

Cloudflare → **Network**:

| تنظیم | مقدار | چرا |
|-------|-------|-----|
| WebSockets | ✅ **حتماً روشن** | بدون این، VLESS/VMess/Trojan کار نمی‌کنند |
| HTTP/2 | ✅ روشن | — |
| HTTP/3 (QUIC) | ✅ روشن | — |
| gRPC | ✅ روشن | برای XHTTP بهتر است |

> ⚠️ **WebSockets حتماً باید روشن باشد.** پیش‌فرض روشن است ولی چک کن.

---

# 🅱️ روش B — دامنه روی Worker (اختیاری)

اگر قبلاً Worker راه انداختی و می‌خواهی روی دامنه شخصی باشد:

1. Cloudflare → **Workers & Pages** → ورکرت را باز کن
2. تب **Settings** → **Domains & Routes** → **Add** → **Custom Domain**
3. بنویس: `edge.yourdomain.com`
4. Cloudflare خودش رکورد DNS و گواهی را می‌سازد

بعد در Railway:
```env
CF_WORKER_HOST=edge.yourdomain.com
```

حالا در پنل، کنار هر کانفیگ Direct یک نسخه CF هم می‌بینی.

---

## 🎯 بهترین ترکیب

```env
PUBLIC_HOST=cdn.yourdomain.com      ← مسیر اصلی
CF_WORKER_HOST=edge.yourdomain.com  ← مسیر پشتیبان
```

دو مسیر مستقل. اگر یکی مشکل پیدا کرد، کاربر روی دیگری سوییچ می‌کند.
در صفحه **Latency Race** می‌توانی ببینی کدام سریع‌تر است.

---

## 🔧 رفع مشکل

### ارور «Too many redirects»
SSL/TLS روی **Flexible** است. بگذار روی **Full**.

### ارور 525 یا 526
- 525 → SSL/TLS را روی **Full** بگذار (نه Full strict)
- 526 → همان، Full strict با Railway مشکل دارد

### ارور 1016 یا Origin DNS error
رکورد CNAME اشتباه است. دوباره از Railway کپی کن.

### Railway می‌گوید «DNS not detected»
- مطمئن شو **CNAME** است نه A
- مطمئن شو پروکسی **خاکستری** است (موقع صدور گواهی)
- رکورد **TXT** را هم ساختی؟

### گواهی SSL گیر کرده روی Validating
ترفند معروف:
1. پروکسی را **خاکستری** کن
2. صبر کن تا Railway تیک سبز بدهد
3. حالا **نارنجی** کن

### VPN وصل می‌شود ولی اینترنت ندارد
Cloudflare → **Network** → **WebSockets** را روشن کن.

### پنل باز می‌شود ولی خراب است
Cloudflare → **Speed** → **Rocket Loader** و **Auto Minify** را خاموش کن.

### لینک‌ها هنوز دامنه Railway دارند
`PUBLIC_HOST` را در Railway تنظیم نکردی، یا بعد از تنظیم کانفیگ را دوباره کپی نکردی.

### همه کاربران یک IP دیده می‌شوند
در نسخه فعلی حل شده — پنل هدر `CF-Connecting-IP` را می‌خواند.
اگر مشکل داشتی مطمئن شو آخرین نسخه را دیپلوی کرده‌ای.
