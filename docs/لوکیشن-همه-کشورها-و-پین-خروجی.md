# 🌍 لوکیشن‌های خروجی: فقط کشورهای دارای رله‌ی تور + فعال‌سازی از پنل + پین آی‌پی خروجی

> وضعیت: **ساخته شده** — بخشی از نسخه‌ی ۳.۳

---

## ۱) فقط کشورهایی که تور واقعاً توشون رله داره

صفحه‌ی **Locations** دیگه همه‌ی جهان رو نشون نمی‌ده — فقط **کشورهایی رو
لیست می‌کنه که توی شبکه‌ی تور رله‌ی خروجی فعال دارن** (بر اساس داده‌ی
زنده‌ی `onionoo.torproject.org`؛ اگه نت در دسترس نباشه، از یک عکس‌فوری
داخلی استفاده می‌شه که همراهش تاریخش درج شده).

- جواب سوالت: **نه، فلسطین رله‌ی خروجی تور نداره** — پس توی پنل نیست.
  (اسرائیل، امارات و چند کشور کم‌رله هستن؛ کشورهای با کمتر از ~۱۰ رله
  برچسب «scarce» می‌گیرن چون معمولاً تأیید نمی‌شن.)
- روی هر کارت، **تعداد رله‌ی خروجی فعال** اون کشور نمایش داده می‌شه.
- بالای لیست: تعداد کل کشورها + اینکه داده زنده‌ست یا داخلی + آخرین
  به‌روزرسانی.
- لیست هر بار دیپلوی (یا هر ۲۴ ساعت) خودکار از شبکه‌ی تور تازه می‌شه.
  با `ONIONOO_REFRESH=0` می‌تونی این به‌روزرسانی رو خاموش کنی.

هر کشور یک کارت جدا داره: پرچم، نام، تعداد رله، وضعیت، و دکمه‌ی
**فعال‌سازی / غیرفعال‌سازی**.

### فارسی

وقتی زبان پنل رو **فارسی** کنی، اسم کشورها هم فارسی می‌شن (مثلاً
«آلمان» به‌جای Germany) و توی کادر جستجو هم می‌تونی **فارسی بنویسی** —
جستجو هم اسم فارسی، هم انگلیسی، هم کد کشور رو چک می‌کنه. توی پورتال
بازیکن و مودال کانفیگ هم اسم کشورها با زبان صفحه هماهنگه.
- فعال‌سازی **بدون ری‌دیپلوی** انجام می‌شه: به محض کلیک، یک نمونه‌ی تور مخصوص اون
  کشور بالا میاد، شروع می‌کنه به بوترپ شدن و تأیید شدن، و وقتی خروجی‌ش تأیید شد
  توی سابسکریپشن‌ها ظاهر می‌شه.
- یه **کادر جستجو** بالای لیست هست که با اسم یا کد کشور فیلتر می‌کنه.
- کشورهای فعال اول لیست میان و بقیه‌ی کارت‌ها کمرنگ‌ترن.

### کشورهای ممنوعه

چند کشور (ایران، چین، روسیه، کره شمالی، سوریه، کوبا، ونزوئلا، بلاروس و بلوک
آسیای مرکزی) **اصلاً توی پنل نمایش داده نمی‌شن**، چون رد شدن ترافیک از
شبکه‌هاشون به‌درد نمی‌خوره یا خطرناکه. اگه خواستی لیست رو عوض کنی:

```
LOCATION_EXCLUDE=ir,kp,cn,ru
```

### سقف تعداد

هر نمونه‌ی تور حدود **۴۰ مگابایت رم** مصرف می‌کنه. سقف پیش‌فرض **۱۰ لوکیشن
همزمان** هست و موقع رد شدن از سقف، پنل دلیلش رو می‌گه. اگه رم کانتینرت
بیشتره می‌تونی بالا ببریش:

```
MAX_LOCATIONS=15
```

### متغیر LOCATIONS

`LOCATIONS` دیگه فقط **سید اولین بوت** هست: همون اول کار توی دیتابیس کپی
می‌شه و از اون به بعد، لیست فعال‌ها دست پنل هست. یعنی می‌تونی با
`LOCATIONS=de,nl,tr` شروع کنی و بعداً بقیه رو از پنل اضافه کنی.

## ۲) پایداری: بهترین آی‌پی‌های خروجی + پین کردن

تور خروجی‌ها رو خودش عوض می‌کنه، ولی پنل حالا براشون **تاریخچه** نگه می‌داره:

- هر کشور فعال، **۵ تا از پایدارترین آی‌پی‌های خروجی** که تا حالا داشته رو
  نشون می‌ده (بر اساس مدت زمانی که اون آی‌پی در خدمت بوده + تعداد اتصال‌ها).
- روی هر آی‌پی یه دکمه‌ی **📌 پین** هست. پین کردن یعنی `ExitNodes <ip>` توی
  کانفیگ تور — با `StrictNodes 1`، **همه‌ی سیکل‌ها از همون یک رله رد می‌شن** و
  آی‌پی خروجی ثابت می‌مونه.
- ⚠️ **هشدار واقعی:** اگه اون رله از دست بره، لوکیشن تا لحظه‌ی لغو پین کار
  نمی‌کنه. برای همین پنل قبل از پین هشدار می‌ده و **لغو پین** هم یک کلیکه.

این برای سرویس‌هایی که آی‌پی خاصی رو وایت‌لیست می‌کنن (مثلاً استریم
منطقه‌ای) عالیه.

## ۳) بهینه‌سازی و پایداری کلی

بدون اضافه شدن شبکه‌ی واسط (طبق انتخابت، WARP اضافه نشد)، این بهبودها
انجام شد:

| بهبود | چه می‌کنه |
|---|---|
| **واتچ‌داگ Xray** | اگه Xray کرش کنه، خودکار بعد از ۴۵ ثانیه ری‌استارت می‌شه (حداکثر هر ۵ دقیقه یک بار، با لاگ رویداد). دیگه تانل مرده منتظر ری‌دیپلوی نمی‌مونه. |
| **DNS محلی اول** | لیست DNS سرورهای Xray با `localhost` شروع می‌شه — رزولور خود کانتینر برای هر چیزی که کش داره فوری جواب می‌ده. |
| **اکوی وب‌سوکت `/__ws`** | مسیر `Latency Race` یک حالت جدید «Tunnel WS» گرفته: پینگ واقعی از داخل تونل (TLS → Cloudflare → nginx) اندازه‌گیری می‌شه، نه با یک درخواست HTTP کوتاه. |
| **پورت‌های پایدار لوکیشن** | پورت هر کشور از کل لیست کشورها مشتق می‌شه، پس فعال/غیرفعال کردن یک کشور هیچ‌وقت پورت کشور دیگه‌ای رو عوض نمی‌کنه. |
| **نوشتن اتمیک torrc** | فایل کانفیگ تور با `rename` اتمیک نوشته می‌شه تا ری‌استارت هم‌زمان یه فایل نصفه‌نویسه نسازه. |
| **لوکیشن‌ها روی WebSocket** | کانفیگ‌های کشورها از HTTPUpgrade به WS منتقل شدن — یک اتصال بلندمدت که روی مسیر تور (سه‌هاپ) به‌صرفه‌تره؛ XHTTP عمداً استفاده نشد چون پست‌های کوچیک زیادش روی تور گرون درمیاد. |
| **بافر سرعت (پیش‌فرض ۱۶MB)** | سطح عادی پالیسی Xray بافر ۱۶ مگابایت گرفت تا دانلودها سریع‌تر برن؛ **توربو مود** و **بوست** همون‌جا به صفر برمی‌گردن برای کمترین پینگ. |
| **XHTTP سریع‌تر** | فاصله‌ی اسلات پست‌ها به `1-3ms` و حجم پست‌ها به `200-500KB` رسید + پدینگ کم‌تر — داده بیشتر، سربار کمتر. |
| **ALPN دوگانه + فینگرپرینت random** | همه‌ی لینک‌ها هم `h2` هم `http/1.1` رو پیشنهاد می‌دن (کلاینت بهترینش رو انتخاب می‌کنه) و `fp=random` جای `chrome` نشست. |
| **تور سریع‌تر (IPv4 + fail-fast)** | هر torrc حالا `ClientUseIPv6 0` داره (Railway خروجی IPv6 نداره، پس درخواست AAAA فقط تأخیر اضافه می‌کرد)، `SocksTimeout 30` و `CircuitBuildTimeout 30` — یعنی سیکلِ روی رله‌ی مرده سریع رها می‌شه و دوباره ساخته می‌شه به‌جای اینکه تانل آویزون بمونه. |
| **nginx API نادلِی** | `tcp_nodelay` به پراکسی API هم اضافه شد تا پاسخ‌های کوچک پنل بلافاصله برن. |

## ۴) چطوری استفاده کنم؟

1. پنل → **Locations**.
2. اسم کشور رو توی کادر جستجو بنویس (یا اسکرول کن).
3. **Activate** رو بزن. کارت می‌شه: `QUEUED → STARTING → VERIFYING → READY`.
   (چند دقیقه طول می‌کشه؛ کشورهای کم‌رله مثل ترکیه بیشتر.)
4. وقتی `READY` شد، آی‌پی خروجی و ۵ خروجی پایدارش رو می‌بینی.
5. اگه آی‌پی ثابت می‌خوای: **📌 Pin** کن (هشدارش رو بخون!) و اگه خراب شد
   **Unpin**.
6. کانفیگ کشور توی سابسکریپشن‌ها ظاهر شده — می‌تونی از پورتال هر بازیکن
   کپی‌ش کنی.

> یادت باشه: این‌ها از تور رد می‌شن و تأخیرشون ۵۰۰ms به بالاست — فقط برای
> سرویس‌های منطقه‌ای، نه برای بازی.
